# 历史处理脚本

此目录保存测试设计和 UI 审查中使用过的生成、修订、结构验证脚本。脚本中的内部链接、人员和本机路径已脱敏。路径以仓库根目录为基准，原 `.work` 输入对应此目录，表格输出对应 `artifacts`。

原始文档读取结果、浏览器 DOM 快照、截图及中间数据留在本地，未随脚本公开。需要相应输入文件的脚本不能仅凭本仓库直接运行；输入中的公开占位链接和人员编号不能还原成原始身份。

JavaScript 工作簿脚本使用 `@oai/artifact-tool`，Python 脚本根据原流程可能使用 Pillow 或 openpyxl。此目录保留历史流程，不声明这些脚本已在公开副本中逐个重跑。检查已发布文件可运行仓库根目录的 `tools/audit_publication.py`。
