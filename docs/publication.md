# 公开发布范围与验证

日期：2026-10-14。

本次沿用目标仓库既有 `main` 历史，增加独立整理的公开快照；没有导入私有工程的提交历史。原工程、原始表格、截图及中间资料保留在本地。

本次范围为当前前端/BFF 源码及本地已有适配、27 份测试表格、124 个历史处理脚本、9 个 UI 审查 Skill 文件和公开文件扫描工具。表格仍保留测试用例、需求要点、观察记录、人工意见和执行状态。公开披露授权需覆盖这些内容。

检查表共保留 6,803 条公式，沿用原有单元格类型、样式、合并、冻结、筛选、条件格式及数据验证。公开包移除 125 个嵌入图像；原图仍在本地。原有测试结果、人工备注与受阻状态没有因发布而升级或清空。

真实 npm 凭据与内部地址未进入公开快照。源码中的演示数据、回环地址、业务字段、用例编号和已有执行状态保留。人员统一改用匿名编号，内部来源链接改为公开占位地址；原始来源标识和作者元数据同时清理。

验证包括对 Git 暂存内容的扫描、对 XLSX 全部 XML/关系文件的扫描、对公式与单元格结构的比较、原文件哈希核对、脚本语法检查和生产构建。表格预览使用现有工作簿引擎，处理截图关系时保持原始 XML 命名空间声明，以确保公开副本能够重新导入。

当前源码的核心层已内联，认证 SDK 仍指向本地授权目录。`pcs-service`、`lmd-service`、`BYAuthCenter` 作为本地参考依赖，不在本次公开清单内。私有源文档、源表备份、历史包、浏览器 DOM、真实配置与运行日志不公开。

最终验证结果与逐份表格记录见 `publication-validation.json`；文件清单见 `public-file-manifest.json`。构建、预览及未执行的验证在记录中分别说明，不沿用此前版本的验证结果。

历史脚本需要的私有源数据和中间输入未公开，本次没有逐个重跑。检查表中的原有执行状态是该次记录的事实范围，发布本身不构成新的环境验收。
